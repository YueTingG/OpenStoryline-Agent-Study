# Experiment Plan

目标：先验证 Agent 的核心剪辑闭环，再逐步验证增强能力。

## Phase 1: 对话能力和工具认知

在 Web 页面输入：

```text
请详细介绍一下你能做什么，并列出你可以调用的剪辑工具。
```

再输入：

```text
我想学习你的工作流。请解释从上传素材到生成视频，中间会经过哪些步骤。
```

记录它是否提到：

- 素材加载
- 镜头切分
- 内容理解
- 镜头筛选
- 片段分组
- 文案生成
- BGM 选择
- 时间线组织
- 渲染成片

## Phase 2: 最小剪辑闭环

准备 2-5 个小视频或图片，先不要太大。

推荐 prompt：

```text
我先不用联网搜素材，也不要配音。请只基于我上传的素材，剪一个 15 秒左右的视频，包含字幕、BGM 和简单转场。请先告诉我你会执行哪些步骤，不要马上开始。
```

确认计划后再输入：

```text
开始剪辑。
```

观察日志：

```powershell
docker logs -f openstoryline-test
```

## Phase 3: 二次编辑

在同一个会话里继续输入：

```text
把整体节奏改得更快一点，删掉无聊的镜头，字幕风格更像小红书。
```

再试：

```text
保留视频结构，但把文案改成更温暖、更有故事感。
```

观察它是否复用已有结果，还是从头跑。

## Phase 4: 风格模仿

输入：

```text
请模仿下面这段文案的语气，为这个视频生成旁白文案：
「今天没有什么宏大的计划，只是想把一些普通的小瞬间，好好收起来。」
```

目标：验证文案风格迁移能力。

## Phase 5: 增强能力

基础闭环跑通后再考虑：

- 配 Pexels API，测试在线搜素材。
- 配 TTS，测试自动配音。
- 添加自定义 BGM，测试音乐推荐。
- 让 Agent 总结剪辑风格并保存为 Skill。
